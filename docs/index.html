browser / terminal / agent control

SURFBOARD

one workspace for the web and the command line. tabs can be a chromium browser or a real terminal, and coding agents can operate the adjacent browser through a local, permissioned mcp connection.

release assets will appear here when the first build is published.

mac builds are currently developer-signed. on first launch, use open from finder if macos shows an unsigned-app warning. checksums are published with every release.

equal-status tabs

create, reorder, close, and move browser and terminal tabs without changing tools or mental models.

real chromium

persistent browsing, downloads, devtools, screenshots, console and network diagnostics, accessibility inspection, and modern web compatibility.

real shell

interactive ptys, resize, unicode, scrollback, colors, links, and child-process cleanup. no command runner pretending to be a terminal.

agent bridge

opt-in local mcp access with a per-user bearer capability. page control is typed and visible; terminal, cookies, raw cdp, shell, and filesystem access are not exposed.

open source

implementation, tests, packaging, and release automation live in the repository.
